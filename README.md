# Implementation-of-AES-Encryption-and-Decryption-using-Verilog--Xilinx-ISE-14.7
# Description 
Designed and implemented an AES-128 (Advanced Encryption Standard) encryption and decryption engine using Verilog HDL. The project follows a modular RTL architecture with dedicated modules for SubBytes, ShiftRows, MixColumns, AddRoundKey, Key Expansion, UART transmission, and top-level integration. Functionality was verified using Python reference outputs, NIST AES-128 test vectors, and RTL simulation in Xilinx ISim.

# Tools & Technologies 
-Verilog HDL
-Python
-Xilinx ISE 14.7
-Xilinx ISim

 # Features 
- Modular AES-128 RTL implementation
-Encryption and decryption support
-Key Expansion (Key Schedule)
-SubBytes, ShiftRows, MixColumns, and AddRoundKey modules
-UART-based ciphertext transmission
-Verilog testbench for functional verification
-Synthesizable RTL design

# Verification
-Verified using standard NIST AES-128 test vectors
-Cross-validated outputs using Python reference implementation
-Performed RTL simulation, waveform analysis, and functional verification using Xilinx ISim
-Executed logic synthesis using Xilinx ISE 14.7

# Applications
-Secure communication systems
-FPGA-based cryptographic accelerators
-Embedded security systems
-Hardware cryptographic processors
-VLSI/ASIC digital security designs

# Results
- Successfully synthesized the AES-128 RTL design using Xilinx ISE 14.7.
- Verified functionality using NIST AES-128 test vectors, Python reference outputs, and RTL simulation.
- Validated a synthesizable and modular hardware implementation for FPGA-based cryptographic applications.
